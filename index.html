SISTEM COMBAT LUNEX

Crystal PvP (CPvP) & Duels Arena

Mekanik pertarungan End Crystal dan Respawn Anchor tanpa jeda tick (no-delay). Sistem duel kompetitif lengkap dengan antrean matchmaking dan spectator mode.

  • Penempatan kristal dan obsidian instan tanpa delay artifisial.
  • Antrean duel 1v1 dengan kit kustom dan arena khusus (/duels).
  • Combat tagging otomatis untuk mencegah logout saat bertarung.

SISTEM PASAR & EKONOMI

Dual Currency, Auction House & Orders

Sistem ekonomi dua mata uang (Uang Saldo & Shard Kristal). Jual beli antar pemain tanpa perantara melalui sistem Auction House dan permintaan beli pesanan (Player Orders).

  • Pasar terbuka Auction House (/ah) dan Order Book pesanan (/orders).
  • Mata uang Shard khusus untuk membuka perlengkapan tingkat lanjut (/shard).
  • Perintah jual cepat /sell, /sellall, dan /sellhand dengan bonus multiplier hingga 1.5x.

Stacking Spawners

Tumpuk spawner di markas tim Anda tanpa menyebabkan beban entitas berlebih. Menghasilkan bahan mentah untuk digiling dan dijual.

Perintah: /rtp, /home, /tpa

KEBIJAKAN KOMUNITAS

ATURAN SERVER LUNEXSMP

Pelanggaran aturan akan langsung ditindak tanpa dispensasi demi menjaga keadilan kompetisi.

Penggunaan software pihak ketiga seperti Killaura, Auto-Totem, Auto-Crystal, Flight, Speed, X-Ray, atau baritone dilarang keras. Sistem pendeteksi otomatis dan staf akan langsung memberikan sanksi ban permanen pada akun terkait.

Memanfaatkan celah keamanan, bug dupe chunk, atau bug sistem ekonomi untuk memperbanyak item secara ilegal berakibat wipe inventaris total dan ban perangkat. Laporkan temuan bug kepada staf di Discord untuk memperoleh hadiah reward.

Trash-talk ringan dalam konteks pertempuran diperbolehkan. Namun, menyebarkan data pribadi pemain lain (doxxing), ancaman fisik dunia nyata, rasisme, atau pelecehan seksual akan langsung dilaporkan dan diproses ke pemblokiran permanen.

Setiap pemain diizinkan memiliki maksimal 1 akun alt semata-mata untuk keperluan AFK spawner di base. Dilarang menggunakan akun alternatif untuk menghindar dari sanksi ban (ban evasion) atau mengeksploitasi sistem kuota hadiah.

Keluar dari server (disconnect / close game) saat status pertempuran (Combat Tag) masih aktif akan memicu eliminasi instan oleh sistem. Seluruh item di inventaris pemain akan jatuh di tempat kejadian.

PANDUAN KONEKSI

CARA BERGABUNG KE SERVER

Mendukung koneksi langsung dari Minecraft Java Edition (PC) dan Bedrock Edition (Android, iOS, Windows 10/11, Konsol).

1
Buka Game: Jalankan Minecraft Java Edition pada komputer Anda. Versi yang disarankan adalah 1.20 hingga versi terbaru.
2
Masuk ke Menu: Klik tombol Multiplayer pada layar utama, kemudian klik Add Server di bagian bawah.
3
Konfigurasi Alamat: Masukkan nama server LunexSMP dan isi Server Address dengan alamat berikut:
play.lunexsmp.my.id:25860
4
Mulai Bermain: Klik tombol Done, pilih server LunexSMP dari daftar, lalu klik Join Server.
1
Buka Game: Jalankan Minecraft Bedrock Edition pada HP (Android/iOS) atau PC Windows Anda.
2
Buka Tab Server: Klik tombol Play, pilih tab Servers, lalu gulir ke bawah dan klik tombol Add Server.
3
Isi Detail Server & Port:
Server Name: LunexSMP
Server Address: play.lunexsmp.my.id
Port Khusus: 19157
4
Masuk ke Arena: Klik tombol Play untuk langsung terhubung, atau Save agar server tersimpan di daftar Anda.
