MEKANIK SERVER LUNEXSMP

ARSITEKTUR COMBAT & EKONOMI

Fondasi permainan kompetitif yang dibangun di atas keseimbangan gameplay: pertarungan Crystal PvP tanpa manipulasi delay dan perputaran ekonomi mandiri antar pemain.

COMBAT SYSTEM

Crystal PvP (CPvP) & Duels Arena

Sensasi bertarung End Crystal dan Respawn Anchor dengan respon tick instan tanpa jeda buatan. Dilengkapi sistem duel otomatis dengan spectator mode untuk menonton pertarungan pemain top.

  • Peletakan Kristal Instan: Mekanik hit dan placing tanpa artificial cooldown untuk combo bertaraf turnamen.
  • Arena 1v1 Terisolasi (/duels): Antrean matchmaking otomatis dengan kit CPvP standar atau kustom.
  • Anti Combat-Log Real-Time: Mencegah pemain kabur saat pertarungan sedang berlangsung dengan sanksi eliminasi otomatis.

MARKETPLACE & TRADING

Dual Currency, Auction House & Orders

Sistem perdagangan terbuka berbasis permintaan pasar. Pemain dapat membuka lapak lelang atau memasang order pembelian barang tertentu secara otomatis.

  • Auction House & Order Book (/ah, /orders): Transaksi aman tanpa resiko scamming atau tipuan drop item.
  • Mata Uang Kristal Shard (/shard): Mata uang bernilai tinggi untuk menempa perlengkapan tempur tingkat elit.
  • Perintah Jual Cepat: Jual inventaris dengan /sell, /sellall, dan /sellhand dengan bonus multiplier rank hingga 1.5x.

KEBIJAKAN & FAIR PLAY

ATURAN RESMI SERVER LUNEXSMP

Setiap pemain wajib mematuhi aturan berikut. Penindakan tegas diberlakukan demi menjaga sportivitas arena.

Penggunaan modifikasi ilegal seperti Killaura, Auto-Crystal, Auto-Totem, Fly, Speed, X-Ray, Baritone, atau script makro otomatis dilarang keras. Sistem pendeteksi otomatis kami serta pengawasan staf aktif akan menjatuhkan sanksi ban permanen pada akun dan perangkat yang terbukti bersalah.

Memanfaatkan celah bug chunk dupe, celah transfer saldo ekonomi, atau bug mekanik untuk memperbanyak item secara ilegal berakibat pada pembersihan inventaris total (wipe) serta ban permanen. Jika Anda menemukan bug, segera laporkan ke tiket staf di Discord untuk memperoleh imbalan hadiah reward resmi.

Saling bersaing dan provokasi taktis ringan dalam suasana PvP wajar terjadi. Namun, penyebaran data pribadi pemain (doxxing), ancaman kekerasan dunia nyata, pelecehan, atau ujaran kebencian berunsur SARA tidak akan ditoleransi dan langsung diproses ke blacklist permanen.

Setiap pemain diperbolehkan memiliki maksimal 1 akun alternatif semata-mata untuk keperluan menjaga AFK spawner di markas. Dilarang memanfaatkan akun alt untuk menghindari sanksi ban (ban evasion) atau melipatgandakan batas klaim hadiah harian.

Keluar dari server (disconnect / close game) ketika status pertempuran (Combat Tag) masih aktif akan otomatis dianggap menyerah. Sistem server akan seketika mengeliminasi karakter Anda dan menjatuhkan seluruh item inventaris di lokasi kejadian.

PANDUAN KONEKSI LUNEXSMP

CARA BERGABUNG KE SERVER

Koneksi mudah langsung dari Minecraft Java Edition (PC/Laptop/Pojav) maupun Bedrock Edition (Android, iOS, Windows 10/11, Konsol).

1

Buka Minecraft Java

Jalankan launcher resmi Minecraft Java Edition Anda. Versi yang didukung adalah 1.20 hingga 1.21+.

2

Buka Menu Multiplayer

Pilih opsi Multiplayer pada layar utama, kemudian klik tombol Add Server di sudut bawah.

3

Masukkan Alamat Server

Beri nama server LunexSMP dan isi kolom Server Address dengan alamat berikut:

play.lunexsmp.my.id
4

Simpan & Mulai Bermain

Klik Done, pilih server LunexSMP dari daftar server Anda, lalu klik Join Server.

1

Buka Minecraft Bedrock

Buka aplikasi Minecraft di HP Android, iPhone/iPad, atau Minecraft for Windows.

2

Masuk ke Tab Servers

Tekan tombol Play, pilih tab Servers di bagian atas, lalu gulir ke bawah dan klik Add Server.

3

Konfigurasi Alamat & Port

Server Name: LunexSMP

Port Khusus: 19132
4

Bergabung ke Game

Tekan Play untuk langsung terhubung, atau tekan Save agar server tersimpan di daftar favorit Anda.
